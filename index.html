Política de privacidad – Majo Anuncios

Última actualización: 14 de octubre de 2026

1. Quién es responsable

"Majo Anuncios" es una aplicación de uso interno de Majo, creadora y vendedora de productos digitales. Contacto: majotolosa.18@gmail.com

2. Para qué sirve la aplicación

La aplicación se conecta a la API de Marketing de Meta únicamente para administrar las cuentas publicitarias, páginas y píxeles propios de su titular: crear, editar, pausar y leer los resultados de sus campañas de anuncios. No es una aplicación pública y no la usan terceros.

3. Qué datos usa

  • Datos de las campañas, conjuntos de anuncios y anuncios propios (textos, imágenes, videos, presupuestos y configuración).
  • Métricas agregadas de rendimiento que entrega Meta (impresiones, clics, costos, conversiones).

    • La aplicación no solicita, recopila ni almacena datos personales de usuarios de Facebook o Instagram, ni de las personas que ven los anuncios.

    4. Cómo se guardan

    Los datos se usan en la computadora de la titular para tomar decisiones sobre sus propios anuncios. El token de acceso se guarda de forma privada y no se comparte. No se venden, alquilan ni ceden datos a terceros.

    5. Cuánto tiempo se conservan

    Los reportes de rendimiento se conservan mientras sean útiles para administrar las campañas y luego se eliminan.

    6. Eliminación de datos

    Como la aplicación no almacena datos personales de usuarios de Meta, no hay datos de terceros para eliminar. Si de todos modos querés hacer una consulta o pedir la eliminación de cualquier dato, escribí a majotolosa.18@gmail.com y se responde en un plazo máximo de 30 días.

    7. Cambios

    Esta política puede actualizarse. La fecha de la última actualización figura al principio.
